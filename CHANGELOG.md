# Changelog

All notable changes to this project are documented in this file.

## 1.0.0 - 2026-04-01

Initial stable release posture for the RiskLab package family.

- Published typed chart surfaces for core, basic, advanced, and 3D lanes.
- Published UI package family with React first and framework-specific variants.
- Standardized playground around `Charts` and `Builder` surfaces.
- Tightened package exports, type entrypoints, and build validation flow.
