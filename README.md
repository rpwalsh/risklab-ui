# RiskLab UI

This repo contains the `@risklab/ui` package and the standalone UI packages for each supported framework.

## Packages

- `@risklab/ui`
- `@risklab/ui-vanilla`
- `@risklab/ui-react`
- `@risklab/ui-vue`
- `@risklab/ui-svelte`
- `@risklab/ui-angular`
- `@risklab/ui-lit`
- `@risklab/ui-solid`

## Install

Vanilla root package:

```bash
npm install @risklab/ui
```

Framework package:

```bash
npm install @risklab/ui-react
```

## Repo Commands

```bash
npm run release:check
npm run build:all
npm run pack:all
npm run smoke:install
```
