# @risklab/ui-react

React UI package for analytical product shells built with RiskLab.

## Install

```bash
npm install @risklab/ui-react
```

## Peer dependencies

- `react >= 18`
- `react-dom >= 18`

## CSS

```ts
import "@risklab/ui-react/css";
```

## Build

```bash
npm run build --workspace=ui/react
```
