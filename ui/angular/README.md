# @risklab/ui-angular

Angular UI package for RiskLab analytical applications.

## Install

```bash
npm install @risklab/ui-angular
```

## Peer dependencies

- `@angular/core >= 17`
- `@angular/common >= 17`

## CSS

```ts
import "@risklab/ui-angular/css";
```

## Build

```bash
npm run build --workspace=ui/angular
```
